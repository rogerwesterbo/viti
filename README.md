# viti
Presentasjon om Viti

Slidev deck about [Vitistack](https://vitistack.io).

```bash
npm install
npm run dev      # http://localhost:3030 (presenter mode: /presenter)
npm run build    # static build to dist/
npm run export   # PDF export (needs playwright-chromium)
```

- `slides.md` – the deck
- `manifests/` – NetworkNamespace and KubernetesCluster YAML used in the demo
- `diagrams/vitistack-flow.excalidraw` – diagram source (open in excalidraw.com, export SVG to `public/vitistack-flow.svg`)
